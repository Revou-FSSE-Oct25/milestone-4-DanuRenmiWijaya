# 🏦 RevoBank Backend API

Proyek backend perbankan modern yang dibangun dengan **NestJS**, **TypeScript**, dan **Prisma ORM**. Sistem ini mendukung manajemen user, rekening, hingga transaksi antar-rekening dengan keamanan tinggi (ACID Transactions).

## 🚀 Fitur Utama
- **Autentikasi & Profil**: Registrasi, Login JWT, dan manajemen profil user.
- **Manajemen Rekening**: Pembuatan rekening ganda per user dengan saldo presisi.
- **Transaksi Aman**: Fitur Setor (Deposit), Tarik (Withdraw), dan Transfer antar-rekening menggunakan *Atomic Transactions*.
- **Audit Trail**: Pencatatan otomatis setiap aktivitas perubahan data sensitif.
- **Dokumentasi Swagger**: API yang terdokumentasi dengan baik dan dapat diuji langsung.

## 🛠️ Stack Teknologi
- **Framework**: [NestJS](https://nestjs.com)
- **Bahasa**: [TypeScript](https://typescriptlang.org)
- **Database**: [PostgreSQL](https://postgresql.org)
- **ORM**: [Prisma](https://prisma.io)
- **Dokumentasi**: [Swagger/OpenAPI](https://swagger.io)
- **Testing**: [Jest](https://jestjs.io)
